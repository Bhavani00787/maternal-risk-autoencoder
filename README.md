# Maternal Risk Classification Using an Autoencoder

## Project Overview

This project explores the use of an **autoencoder for latent representation learning** and a **Multilayer Perceptron (MLP)** for maternal health risk classification. The autoencoder compresses six input features into a two-dimensional latent representation, which is then used by the MLP to classify maternal health risk levels.

This is an academic machine learning project and is not intended for clinical diagnosis or medical decision-making.

## Objectives

- Explore maternal health data using exploratory data analysis.
- Preprocess numerical features using standardization.
- Learn compact latent representations using an autoencoder.
- Classify maternal health risk levels using an MLP.
- Evaluate reconstruction quality and classification performance.

## Dataset

The project uses the Maternal Health Risk dataset.

- **Number of records:** 1,014
- **Number of columns:** 7
- **Input features:** Age, SystolicBP, DiastolicBP, BS, BodyTemp, HeartRate
- **Target:** RiskLevel
- **Missing values:** 0

The target contains three classes: `low risk`, `mid risk`, and `high risk`.

## Methodology

### 1. Data Preprocessing

- Checked the dataset structure and missing values.
- Encoded the categorical risk labels using LabelEncoder.
- Split the data into training, validation, and testing sets using stratification.
- Applied StandardScaler, fitted only on the training set.

| Dataset split | Records |
|---|---:|
| Training | 709 |
| Validation | 152 |
| Testing | 153 |

### 2. Autoencoder Architecture

The autoencoder learns a compact representation of the six input features.

**Architecture:** `6 → 4 → 2 → 4 → 6`

- Encoder: 6 input features → 4 ReLU units → 2-dimensional latent space
- Decoder: 2 latent features → 4 ReLU units → 6 reconstructed features
- Loss function: Mean Squared Error (MSE)
- Optimizer: Stochastic Gradient Descent (SGD)
- Learning rate: 0.01
- Batch size: 32
- Maximum epochs: 300
- Early stopping: Patience of 20 epochs

### 3. Latent Representation and Classification

The two-dimensional latent representation generated by the encoder is used as input to an MLP classifier.

**MLP architecture:** `2 → 16 → 8 → 3`

- Hidden-layer activation: ReLU
- Output activation: Softmax
- Loss function: Sparse Categorical Crossentropy
- Optimizer: SGD
- Learning rate: 0.01
- Batch size: 32
- Maximum epochs: 300
- Early stopping: Patience of 25 epochs

## Results

### Autoencoder Results

| Metric | Result |
|---|---:|
| Final training loss | 0.3131 |
| Final validation loss | 0.3504 |
| Test reconstruction MSE | 0.3704 |

The latent-space visualization shows overlap among the three risk classes, indicating that the learned two-dimensional representation does not completely separate them.

### Classification Results

| Metric | Test result |
|---|---:|
| Accuracy | 51.63% |
| Macro F1-score | 0.5077 |
| Weighted F1-score | 0.5094 |

### Per-Class Performance

| Risk class | Precision | Recall | F1-score |
|---|---:|---:|---:|
| High risk | 0.85 | 0.41 | 0.56 |
| Low risk | 0.49 | 0.72 | 0.58 |
| Mid risk | 0.42 | 0.35 | 0.38 |

The results demonstrate that the autoencoder-based representation can be used for classification experiments, but performance varies across classes. The overlap in latent space may limit class separation.
